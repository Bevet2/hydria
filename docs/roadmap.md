# Roadmap technique

Le programme produit Hydria OS est décrit dans la [feuille de route en quatre chantiers](hydria-os-four-workstreams-2026-10-20.md) : amélioration des workspaces, ArtCraft, fonctions Microsoft et nouveaux usages à évaluer.

## V1

- boucle agentique modulaire
- memoire JSON + SQLite existant
- knowledge store local
- tools registry
- evaluateur heuristique
- orchestration branchee sur `/api/chat`

## V1.1

- memory scoring plus fin
- critic multi-passes
- recherche documentaire plus robuste
- replay de taches reussies

## V2

- indexation locale plus forte
- boucle d’auto-amelioration controlee
- agents specialises supplementaires
- runtime navigateur plus profond
- provider plugins et evals comparatives de versions
